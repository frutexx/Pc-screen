Zjištění komponent počítače

Postupuj podle návodu. Příkaz pouze vypíše informace o počítači – nic nemění ani nemaže.

  1. Stiskni současně WIN + R.
  2. Napiš powershell a stiskni ENTER.
  3. Klikni na tlačítko Kopírovat příkaz níže.
  4. Vlož příkaz do okna PowerShell pomocí CTRL + V a stiskni ENTER.
  5. Až se zobrazí výsledky, stiskni WIN + SHIFT + S, označ výsledky a pošli screenshot.

Příkaz do PowerShellu

Get-CimInstance Win32_Processor | Select Name; Get-CimInstance Win32_BaseBoard | Select Manufacturer,Product; Get-CimInstance Win32_PhysicalMemory | Select @{N="RAM GB";E={[math]::Round($_.Capacity/1GB)}},Speed; Get-CimInstance Win32_VideoController | Select Name; Get-PhysicalDisk | Select FriendlyName,@{N="Disk GB";E={[math]::Round($_.Size/1GB)}}

Příkaz se nespustí automaticky. Syn ho musí sám vložit a potvrdit v PowerShellu.
